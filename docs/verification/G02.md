## 驗證說明

- **方向慣例**: `minutes_forward` 是「from → to」方向的時間，`minutes_backward` 是反向時間
- **上河圖判讀**: 兩個數字中**較小的是下行**（順海拔下降），**較大的是上行**（順海拔上升）

- 如果 `from` 較低、`to` 較高（fwd 為上行）：fwd 應為較大值
- 如果 `from` 較高、`to` 較低（fwd 為下行）：fwd 應為較小值
